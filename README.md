# Словарные слова — карточки для печати

Список словарных слов по классам → карточки А6 для распечатки, вырезания и вклеивания в тетрадь.

## Структура

- `input/1-class.md`, `input/2-class.md`, ... — исходный список слов по классу, один пункт на строку (номер + слово через таб). Можно редактировать вручную, порядок в файле не важен — при вёрстке слова всё равно сортируются по алфавиту.
- `output/1-class-print.html`, `output/2-class-print.html`, ... — готовый к печати результат для соответствующего класса (сюда же смотреть для печати, руками не редактировать — пересобирается из `input/`).
- `.claude/skills/printing-vocabulary-cards/` — инструкция для AI-ассистента, как из списка слов собрать печатную вёрстку (формат, размер карточек, подбор шрифта, где выделять жирным). Пересобрать `output/*-print.html` под новый список слов может ассистент Claude Code — попросите его подготовить конкретный `input/N-class.md` к печати.
  - `assets/generate_cards.py` — сам генератор вёрстки (пагинация, сетка, тайлинг на А4) из уже готового списка слов с расставленными орфограммами.
  - `assets/xlsx_to_json.py`, `assets/compare_orthograms.py` — сверка орфограмм с эталонным файлом, см. ниже.

## Как печатать

1. Открыть нужный `output/*-print.html` в браузере.
2. Печать (Cmd+P / Ctrl+P).
3. Параметры печати: бумага — А4, поля — «Нет» (None), масштаб — 100%, фоновая графика — не нужна.
4. На листе — 4 карточки А6 (105×148 мм), по пунктирным линиям разрезать.

Если слов в списке больше, чем помещается на одну карточку, получится несколько листов — как страницы книжки, карточки идут по порядку, каждая содержит свою часть списка по алфавиту. Межстрочные отступы одинаковые на всех карточках; если последняя карточка неполная, свободное место остаётся просто пустым в конце последней колонки, а не растягивается на всю карточку.

## Проверка орфограмм по эталону (опционально)

Если есть файл с уже проверенной разметкой орфограмм (например от учителя или из методички) — можно отдать его ассистенту вместе с запросом на подготовку карточек, и он сверит свой разбор с эталоном перед тем, как собрать финальный `*-print.html`, и покажет расхождения. Сейчас поддерживается **xlsx** (орфограмма выделена полужирным по буквам внутри ячейки); другие форматы можно добавить по той же схеме.
