# Словарные слова — карточки для печати

Список словарных слов по классам → карточки А6 для распечатки, вырезания и вклеивания в тетрадь.

## Структура

- `1-class.md`, `2-class.md`, ... — исходный список слов по классу, один пункт на строку (номер + слово через таб). Можно редактировать вручную, порядок в файле не важен — при вёрстке слова всё равно сортируются по алфавиту.
- `1-class-print.html`, `2-class-print.html`, ... — готовый к печати результат для соответствующего класса.
- `.claude/skills/printing-vocabulary-cards/` — инструкция для AI-ассистента, как из списка слов собрать печатную вёрстку (формат, размер карточек, подбор шрифта, где выделять жирным). Пересобрать `*-print.html` под новый список слов может ассистент Claude Code — попросите его подготовить конкретный `N-class.md` к печати.

## Как печатать

1. Открыть нужный `*-print.html` в браузере.
2. Печать (Cmd+P / Ctrl+P).
3. Параметры печати: бумага — А4, поля — «Нет» (None), масштаб — 100%, фоновая графика — не нужна.
4. На листе — 4 карточки А6 (105×148 мм), по пунктирным линиям разрезать.

Если слов в списке больше, чем помещается на одну карточку, получится несколько листов — как страницы книжки, карточки идут по порядку, каждая содержит свою часть списка по алфавиту.
